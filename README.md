# WebSocket Tiny2D Physics Simulator

WebSocketを用いたサーバー駆動型のリアルタイム2D物理シミュレーションシステムです。
軽量な2D物理エンジン「Tiny2D.js」の演算コアをNode.js（サーバー側）で完全にホストし、ブロードキャスト配信された等時性座標データをHTML5 Canvas上に100%素直にレンダリングする、疎結合なリアルタイム・モニターアーキテクチャを採用しています。

## 🚀 特徴

- **サーバーサイド物理演算 (SSPE):** `engine.step()` を含むすべての幾何衝突判定（円・矩形・線分）および自由落下・反射・応答ベクトル計算をNode.js側で一元管理。
- **データ駆動型クライアント:** フロントエンド（ブラウザ）は複雑な予測やバッファリングを排し、受信したシミュレーション・スナップショットをそのまま描画する「純粋な再生機」として機能。
- **軽量パイプライン:** 物理エンジンの内部高精度ベクトルデータを、シリアライズに最適なフラットなプレーンオブジェクト（DTO）へ射影し、WebSocket（ws）経由で超低遅延ブロードキャスト。

## 🛠️ システム構成

- **バックエンド:** Node.js, `ws` (WebSocket Server)
- **物理コア:** `Tiny2D.js` (CommonJSインポート仕様)
- **フロントエンド:** HTML5 Canvas, Vanilla JavaScript (Web標準技術のみ)

## 📦 導入・実行手順

### 1. 依存パッケージのインストール
プロジェクトのルートディレクトリで以下のコマンドを実行し、WebSocketサーバーモジュールをインストールします。

```bash
npm install ws
2. ファイル配置の確認
同一の作業ディレクトリ内に以下のファイルが正しく配置されていることを確認してください。

Plaintext
2Ddemo-sim/
├── Tiny2D.js        # 2D物理エンジンコア
├── server.js        # Node.js 物理演算・配信サーバー
└── index.html       # フロントエンド・モニター画面
3. 物理演算サーバーの起動
ターミナルからサーバーを起動します。

Bash
node server.js
正常に起動すると、コンソルに === 物理シミュレーションサーバー（原点回帰版）起動完了 === と表示され、ポート 8080 で接続待機状態になります。

4. モニター画面の表示
ブラウザで index.html を直接開くか、ローカルサーバー経由でアクセスします。
接続が確立された瞬間から、サーバー側でパチンコ状に配置された固定ピン（静的円オブジェクト）や、傾いたオレンジの傾斜ライン（線分オブジェクト）の間を、動的な円オブジェクト（ボール）が純正の物理アルゴリズムに従って滑らかに衝突・バウンスしながら自由落下するシミュレーションがリアルタイムに同期描画されます。

⚙️ シミュレーション仕様
配信クロック: 50ms（固定周期ステップ）

タイムステップ: engine.step(0.01)

ライフサイクル管理: 画面外（下部・側方）へ逸脱した動的オブジェクトは、内部の物理位置ベクトルおよび速度ベクトルが自動的に上部へ安全にリセット（リキッド・リスポーン機構）され、永続的なシミュレーション駆動を実現します。
